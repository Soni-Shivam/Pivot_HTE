Faultline safety memory

Shareable regression claims for a driving controller, read live from Arkiv (one entity per model, version and category) and checked against the owner's memory anchors on 0G Galileo. No backend: this page talks to the public Arkiv and Galileo RPCs from your browser. Trajectories and configs are not here; they stay sealed on 0G Storage for auditors with the owner's key.
